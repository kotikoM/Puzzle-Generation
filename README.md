# 🧩 Bezier Curve Puzzle Generation

Simple puzzle generation algorithm for generating puzzle patterns using two cubic Bézier curves. The project focuses on procedural
puzzle design, leveraging mathematical curves to create visually appealing and complex shapes.

## 📂 Project Structure

- **Source Code**: Available in the [`src`](src) directory.
- **Documentation**: For a detailed explanation refer to [`github.io page`](https://kotikom.github.io/Puzzle-Generation/).
- **Results**: Example generated puzzles can be found in the [`results`](results) directory.
